# SUPPLYCHAINOPTIMIZATION
# Supply Chain Optimization Using Machine Learning

## 📌 About The Project

This project uses Machine Learning to optimize supply chain operations. It helps businesses reduce costs, identify supplier risks, and predict future demand.

## 🎯 What It Does

- **Demand Forecasting** - Predicts product demand for next 30 days
- **Supplier Segmentation** - Groups suppliers by performance (Good, Average, Risky)
- **Anomaly Detection** - Finds suspicious transactions
- **Cost Optimization** - Identifies potential savings

## 🛠️ Tech Stack

- Python
- Jupyter Notebook
- Pandas, NumPy
- Scikit-Learn
- Matplotlib, Seaborn

## 📊 Dataset

- 100 rows, 24 columns
- Features: Sales, Cost, Lead Time, Defect Rate, Delivery Time, etc.
